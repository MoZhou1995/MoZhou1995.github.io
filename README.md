# Mo Zhou — Academic Homepage

This repository contains the source code for Mo Zhou's bilingual academic website.

**Live website:** [https://mozhou1995.github.io/](https://mozhou1995.github.io/)

## Overview

The website provides Chinese and English versions of:

- Academic biography and news
- Research interests and publications
- Research group information
- Teaching information

## Technical Details

The site is built with static HTML and CSS, with minimal JavaScript for the footer year. It is hosted directly through GitHub Pages and does not require a build system.

## Repository Structure

```text
├── index.html, research.html, group.html, teaching.html
├── en/                 # English pages
├── assets/
│   ├── css/            # Shared styles
│   ├── js/             # Minimal JavaScript
│   ├── images/         # Profile and group photographs
│   └── files/          # Academic documents
└── 404.html            # Bilingual not-found page
```

## Local Preview

Open the repository in VS Code and use the **Live Server** extension, or serve the directory with any local static web server. The Chinese homepage is `index.html`, and the English homepage is `en/index.html`.
